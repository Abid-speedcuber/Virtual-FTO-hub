    How chords, modes, and depth work

    A+F means hold A, then press F. A F means tap A, then F within 1.4 seconds. Use physical codes such as KeyF, ShiftLeft, or Numpad8 when needed. A trigger can have one action per mode; other modes may reuse it.

    Bindings and modes save separately for every puzzle size. On every size, Tab switches CIF/EIF-R and C switches CIF/EIF-L. On 3×3, M switches CIF/E– cntr. F/J do U′/U. Numbers 2–9 select width; 0 selects 10 and 1 selects 11. Shift+1–9 select 11–19 and Shift+0 selects 20. Shift holds Slice on every size. On 3×3, Space also selects Wide; Ctrl-wide and Alt-reverse start unbound. Add a next-move slice suffix to stack with a width without holding a key. Full-size widths are cube rotations, which can also be bound directly. Tap a suffix to select it on release for one accepted turn; unmapped keys and mode switches leave it waiting. Tap it again to clear it. Hold a suffix for 200 ms, or use it with a turn sooner, to apply it repeatedly until release. E– cntr uses F/D = U/U′, J/U = 2R′/2R, K/I = R′/R; M returns to CIF. Backspace undoes and Shift+Backspace redoes. After a timed solve, you can undo later free-play moves back to the solved state. Escape pauses an active timed solve; any key resumes without making a move.

    TPS counts accepted manual turns, including sticker drags and clicks. Depth keys, mode switches, held actions, undo/redo, auto-repeat, and automatic scrambles do not count. Peak and total reset with Reset input stats; the window is a trailing rolling average.
